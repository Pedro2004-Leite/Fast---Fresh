# Alertas de loja - UI

App de telemóvel (390 x 844) que avisa os funcionários de ruturas de stock, produtos errados e câmaras sem imagem.
Next.js (App Router), TypeScript e Tailwind 4.

Como correr e como trabalhar nela está no `CLAUDE.md` da raiz do repositório.

```bash
cd ui
npm install
npm run dev -- -p 3100
```

Testes e verificações:

```bash
npm test
npm run lint
npx tsc --noEmit
```
